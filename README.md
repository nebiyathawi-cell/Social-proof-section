# Frontend Mentor - Social Proof Section

This is my solution to the Social Proof Section challenge from Frontend Mentor.

## Overview

### The Challenge

The goal was to build a responsive social proof section featuring customer testimonials and star ratings.

Users should be able to view a clean, organized layout on both mobile and desktop screens.

### Screenshot

![](Screenshot%20(37).png)

## Built With

- HTML5
- Tailwind CSS
- Responsive design principles

## Features

- Responsive layout for mobile and desktop screens
- Staggered star rating boxes
- Staggered customer testimonial cards
- Customer profile images and verified buyer labels
- Consistent colors, spacing, and typography

## What I Learned

While building this project, I practiced:

- Using CSS Grid to create responsive layouts.
- Using Flexbox to align elements.
- Applying Tailwind CSS utility classes.
- Creating staggered layouts with responsive positioning.
- Using responsive breakpoints to adapt designs to different screen sizes.
- Formatting HTML code with Prettier.
- Using Git and GitHub to manage and publish my project.

## Getting Started

To view this project locally:

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
